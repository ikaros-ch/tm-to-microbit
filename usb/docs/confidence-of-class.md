# Confidence of class

How sure the model is about this class right now, 0 to 100 (0 if unknown).

```sig
teachable.confidenceOfClass("Class 2")
```

## Parameters

* **label**: class name exactly as written in Teachable Machine

## Example

```blocks
teachable.confidenceOfClass("Class 2")
```

```package
teachable-machine-usb=github:ikaros-ch/tm-to-microbit/usb
```
