# Web button pressed

True while the web app's button is held down.

```sig
teachable.webButtonPressed(teachable.WebButton.One)
```

## Parameters

* **button**: which web button

## Example

```blocks
teachable.webButtonPressed(teachable.WebButton.One)
```

```package
teachable-machine-usb=github:ikaros-ch/tm-to-microbit/usb
```
