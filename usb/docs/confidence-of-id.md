# Confidence of id

How sure the model is about the class with this ID right now, 0 to 100 (0 if unknown).

```sig
teachable.confidenceOfId(2)
```

## Parameters

* **id**: class ID

## Example

```blocks
teachable.confidenceOfId(2)
```

```package
teachable-machine-usb=github:ikaros-ch/tm-to-microbit/usb
```
