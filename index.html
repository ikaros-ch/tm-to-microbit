How to use

    
    
      
  1. In a MakeCode project open Extensions and paste one of these:
        
    Bluetooth (removes radio, USB still works): https://github.com/ikaros-ch/tm-to-microbit/bluetooth
        
    USB only (keeps radio): https://github.com/ikaros-ch/tm-to-microbit/usb
        
    Use the Teachable Machine blocks and download. Or flash a ready-made test (shows icons for “Class 1/2/3”):
        Bluetooth · USB.
    2. 
      
  2. In Teachable Machine: Export model → Upload, copy the shareable link, paste it above, press Load.
    3. 
      
  3. Press Bluetooth, or plug the micro:bit in (on a phone, with an OTG / USB-C cable) and press USB.
    4.
