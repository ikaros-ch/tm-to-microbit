Teachable Machine → micro:bit

Image, pose and audio models are supported.
The number next to each class is its ID for the “class ID” blocks. You can change it.

How to use

    
    
      
  1. In a MakeCode project open Extensions and paste one of these:
        
    Bluetooth (removes radio, USB still works): https://github.com/ikaros-ch/tm-to-microbit/bluetooth
        
    USB only (keeps radio): https://github.com/ikaros-ch/tm-to-microbit/usb
        
    Use the Teachable Machine blocks and download. Or flash a ready-made test (shows icons for “Class 1/2” and ID 3):
        Bluetooth · USB.
    2. 
      
  2. For Bluetooth: in MakeCode open ⚙ → Project Settings and select No Pairing Required. Don’t use music blocks with Bluetooth (error 070); use the USB extension instead.
    3. 
      
  3. In Teachable Machine: Export model → Upload, copy the shareable link, paste it above, press Load.
    4. 
      
  4. Press Bluetooth, or plug the micro:bit in (on a phone, with an OTG / USB-C cable) and press USB.
    5.
